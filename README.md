# Recorder Keyboard releases

Signed APKs of Recorder Keyboard, published by Recorder's release workflow whenever the keyboard's `main` changes. Recorder itself is released separately in [callrecorder-releases](https://github.com/AKolenda/callrecorder-releases).

In [Obtainium](https://github.com/ImranR98/Obtainium), add `https://github.com/AKolenda/recorder-keyboard-releases`, or use [Add to Obtainium](obtainium://add/https://github.com/AKolenda/recorder-keyboard-releases). If GitHub doesn't open the app link, use [the browser redirect](https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/AKolenda/recorder-keyboard-releases). No other settings are needed. Enable Obtainium's background update checks and automatic installation if you want updates installed automatically.

The APK is signed with Recorder's key, so install Recorder first; its dictation permission requires the same signature.
