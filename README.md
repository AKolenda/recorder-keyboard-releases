# Recorder Keyboard releases

Signed APKs of Recorder Keyboard, published by `AKolenda/recorder-keyboard` on every push to `main`.

In [Obtainium](https://github.com/ImranR98/Obtainium), add `https://github.com/AKolenda/recorder-keyboard-releases`, or use [the browser redirect](https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/AKolenda/recorder-keyboard-releases). No other settings are needed.

The APK is signed with Recorder's key, so install Recorder first; its dictation permission requires the same signature.
